Comments setup

Configure Artalk

Comments are an external dynamic service. Fileloom can connect to a local Artalk sidecar through its same-origin proxy or to an external Artalk URL; Artalk owns identities, moderation, rate limits, and comment storage. The default is off.

Local Artalk

Install the sidecar

Fileloom will not run sudo, download binaries, or create system services from a browser request. Run this idempotent command in the Fileloom repository, then return here and choose local mode.

sudo ./scripts/install-artalk.sh
