# Screenshots

The screenshots in this directory are captured from the Fileloom dashboard/editor running locally through a header-injecting development proxy.

- `dashboard-mobile-clean.png` — responsive dashboard with themes and Git workflow.
- `dashboard-comments-off.png` — dashboard with the default-off Comments panel, local sidecar detection surface, and install action.
- `dashboard-artalk-install.png` — local Artalk installer command dialog.
- `theme-tokens-mobile.png` — CSS custom-property editor.
- `editor-desktop-source.png` — desktop HTML source editor with protected front matter notice.
- `editor-mobile-code.png` — mobile responsive code-block editor.
